ミツカル採用

面接の日程調整をチャット上で自動的に成立させる、新卒採用向けの Web アプリのデモです。

2分25秒 / 音声はありません

動画の流れ

  1. 人事が学生を選び、対象期間と担当面接官を指定して日程調整依頼を送る
  2. 学生がチャット上のカレンダーから、都合のいい時間を選んで送る
  3. サーバーが学生の候補時間と面接官の空き予定を照合し、未登録の時間帯だけ面接官に確認を送る
  4. 面接官が通知内のボタンで回答すると、全員が空いている時間が確定し、学生と人事に自動で通知が届く
  5. 面接官が自分の空き予定をカレンダーに登録する画面（動画の後半）

設計や実装の詳細は GitHub のリポジトリ にあります。
